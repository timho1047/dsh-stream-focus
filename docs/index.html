What changed

Less chasing. More reading.

DSH already streams well. This plugin removes the last rough edges: the current step stays visible, movement is eased, and native chrome stays native.

Follows the run

The newest thinking or tool call opens automatically. Previous automatic rows fold when the step moves on.

Frame-paced reveal

Characters arrive by animation frame instead of chunk. Grapheme boundaries keep accents and emoji intact.

Mode-aware structure

Grouped window behavior in Compact and Standard; flat-row pacing in Detailed and Verbose.

Focus-safe

Automatic clicks never steal focus or leave a ring behind. Keyboard focus stays exactly where the user put it.

Native by design

No injected background, border, radius, or padding. The window uses the official process-group surface.

Zero settings

Enable the plugin and refresh. There is nothing to tune, no session data to write, and no network calls to make.

Four modes, one plugin

Behave like the mode you chose.

Compact and Standard keep the official process group. Detailed and Verbose keep their flat rows. The plugin adapts instead of forcing one shape everywhere.

Get started

One command. Zero settings.

Install from npm, refresh the DSH Web UI, and keep working. The plugin only touches the running Turn and restores the official view when it ends.

DSH ≥ 0.2.1-rc.2 Node ≥ 22.19 MIT
terminal
$ dsh plugin --profile web add dsh-stream-focus

Then refresh the DSH Web UI. Works in all four Work details modes.
